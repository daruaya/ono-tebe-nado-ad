# Оно тебе надо

Одностраничный сайт аукциона необычных вещей, в которые никто не верил.

## О проекте

Проект создан в рамках учебной работы Яндекс Практикума.

На сайте представлены:
- Главная страница с описанием аукциона.
- Карточки с необычными лотами.
- Информация об аукционе.
- Контактная информация.
- Ссылки на социальные сети.

## Технологии

- HTML5
- CSS3
- Flexbox
- Grid Layout
- Семантическая вёрстка

## Структура проекта

- `index.html` — главная страница.
- `styles/` — файлы стилей.
- `fonts/` — шрифты.
- `images/` — изображения и иконки.
